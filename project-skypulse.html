SkyPulse: Real-Time Weather Application

A modern, interactive weather application featuring dynamic glassmorphism theming, live 5-day forecasts, and intelligent location geocoding.

View on GitHub ↗

Challenge

Creating a visually stunning and highly responsive weather application that not only displays accurate real-time data but also provides an exceptional user experience through intelligent search and dynamic theming.

Solution

Built a lightning-fast React application using Vite. Integrated the Open-Meteo API for real-time weather and forecasting without API keys, and implemented a custom debounced auto-complete search to accurately resolve city names to geographical coordinates.

Architecture Highlights

  • Dynamic Theming: The application automatically shifts its CSS gradient background based on current weather conditions (e.g., sunny, night, rainy).
  • Intelligent Geocoding: Implemented a debounced search dropdown that hits a geocoding API to let users pick precise locations globally.
  • Premium UI/UX: Utilized glassmorphism design principles with custom scrollbars, micro-animations, and responsive layouts.

Technologies

React, Vite, JavaScript, HTML5, Vanilla CSS, Axios, Open-Meteo API

Outcome

  • Delivered a highly performant and visually striking frontend application.
  • Solved common API ambiguities (like duplicate city names) through an intuitive auto-complete search interface.
  • Deployed seamlessly using modern web architecture and automated pipelines.
